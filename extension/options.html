How to group
Automatic grouping

Tav runs two small AI models on this computer: one to find related tabs, one to suggest names. The first run downloads them (about 80 MB) from Hugging Face; after that they're cached. Tab titles never leave this computer.

Higher keeps groups tighter and leaves more tabs alone. Lower groups more loosely.

Model

Uses the model Tav already downloads for automatic grouping. Nothing to set up.

Also turn it on in about:config: set browser.ml.enable and extensions.ml.enabled to true. Firefox downloads the model the first time.

Where layad is listening (check with layad status). Only 127.0.0.1 addresses are allowed.

Categories

Tabs the model is less sure about than this are left where they are.

The name becomes the group title. The model reads the description to decide what belongs, so describe the contents rather than just naming them.
